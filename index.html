🎯 a) Problema y contexto

Desafío: SolarCharge — Simulador de carga de baterías mediante energía solar.

Beneficiarios: estudiantes, comunidades con acceso limitado o inestable a la electricidad y pequeños emprendimientos interesados en energía solar.

Problema: es útil estimar cuándo una batería alcanzará una carga determinada para planificar el uso de la energía disponible. El simulador estudia esta situación mediante un modelo educativo simplificado, no mediante mediciones reales.

Pregunta: ¿Cuánto tiempo se necesita para alcanzar el 90 % de carga y cuál de los métodos Heun y RK4 aproxima mejor la solución exacta?

📚 Modelo matemático

La velocidad de carga se supone proporcional a la capacidad que falta por llenar. Así se obtiene la siguiente EDO de primer orden:

dE/dt = k (Emax − E)

c) Solución analítica y comprobación

Separando variables: dE/(Emax − E) = k dt. Al integrar: −ln|Emax − E| = kt + C. Despejando y aplicando E(0) = E0 se obtiene:

Solución analítica: E(t) = Emax − (Emax − E0)e−kt

Verificación: derivando la solución, E′(t) = k(Emax − E0)e−kt. Al sustituir E(t) en el lado derecho de la EDO se obtiene exactamente la misma expresión. Además, E(0) = Emax − (Emax − E0) = E0.

d) Métodos numéricos

En ambos métodos se usan los mismos parámetros, condición inicial, intervalo y paso h. Se define f(t,E) = k(Emax − E).

Heun: k1 = f(tn, yn), k2 = f(tn + h, yn + hk1).

Heun: yn+1 = yn + h(k1 + k2)/2

Para RK4: k1 = f(tn, yn); k2 = f(tn + h/2, yn + hk1/2); k3 = f(tn + h/2, yn + hk2/2); k4 = f(tn + h, yn + hk3).

RK4: yn+1 = yn + h(k1 + 2k2 + 2k3 + k4)/6

Error absoluto: |Eexacto − Eaproximado|. Error relativo (%): 100 × error absoluto / |Eexacto| (cuando no es cero).

Supuestos: k constante, disponibilidad solar suficiente, sin consumo simultáneo, sin pérdidas ni envejecimiento. Este modelo matemático es hipotético y no predice la carga real de una batería o panel solar.

💡 f) Interpretación y conclusiones

El tiempo para la meta se muestra arriba y los errores finales aparecen en la comparación de pasos. Esos resultados permiten evaluar qué método se acerca más a la solución analítica y cómo cambia la precisión al reducir h.

Aplicación para la comunidad: el modelo sirve para comprender cómo una carga idealizada se acerca a su capacidad máxima y para explorar escenarios educativos de planificación energética.

Limitaciones: se supone k constante, energía solar suficiente y ausencia de consumo, pérdidas, calentamiento y envejecimiento. No debe usarse para prometer tiempos reales de carga ni dimensionar una instalación solar sin un modelo físico y datos medidos.

Conclusión: en los parámetros de ejemplo, RK4 presenta menor error que Heun. Comprueba el resultado con los valores que ingreses: el método ganador se indica automáticamente en el panel superior.
